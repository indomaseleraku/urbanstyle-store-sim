# 🛍️ UrbanStyle Store — Sistem Informasi Manajemen (SIM)

Platform E-Commerce LifeWear berbasis Next.js 16, Tailwind CSS, dan TypeScript untuk pemenuhan tugas mata kuliah **Sistem Informasi Manajemen (SIM)**.

---

## 🚀 Cara Menjalankan Proyek

1. **Clone repositori:**
   ```bash
   git clone https://github.com/indomaseleraku/urbanstyle-store-sim.git
   cd urbanstyle-store-sim
   ```

2. **Instal dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server development:**
   ```bash
   npm run dev
   ```

4. Buka browser di **[http://localhost:3000](http://localhost:3000)**.  
   Aplikasi langsung siap digunakan dengan data lokal katalog pakaian, keranjang, checkout QRIS & bank, dan dashboard admin (`/admin/login`).

---

## 📦 Skema Database (Opsional)
Jika ingin menghubungkan ke database cloud Supabase, script SQL sudah tersedia di file `supabase_schema.sql`.
